## 2. Cara Menguji Pratinjau Open Graph di WhatsApp

1. Jalankan API & Web di server HTTPS publik (atau tunnel seperti Cloudflare Tunnel / ngrok yang mengarah ke origin aplikasi dengan `APP_BASE_URL` sesuai domain tunnel).
2. Kirim tautan OG `https://<domain>/api/og/s/sdn-01-demo/hari-ini?to=kalkulator` (atau lewat tombol **Bagikan WA**).
3. Crawler WhatsApp membaca tag `og:title`, `og:description`, dan `og:image` dari [og.ts](../../apps/api/src/routes/og.ts), sedangkan saat orang tua mengetuk tautan di WhatsApp, halaman langsung mengarahkan ke `/kalkulator?school=sdn-01-demo`.
