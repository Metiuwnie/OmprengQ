## 3. Kepatuhan Prinsip PRD & Aksesibilitas

- **Tanpa label status gizi:** Tidak ada label "obesitas", "kurus", atau "stunting" di halaman `/`, `/admin`, maupun `/dev/design`.
- **Target sentuh >= 44px:** Komponen `Button` memakai `min-h-11` (`44px`).
- **Aksesibilitas:** `:focus-visible` ring aktif, `prefers-reduced-motion: reduce` didukung, `overflow-x: clip` pada `html, body`, progress bar memakai `role="progressbar"` dan animasi `transform: scaleX()` (bukan `width`).
- **Ikonografi:** Memakai SVG Lucide, tanpa emoji sebagai ikon.
- **Tanpa hex literal di komponen:** Semua komponen UI memakai token semantik Tailwind/shadcn (`bg-background`, `bg-card`, `bg-accent`, `bg-primary`, `bg-mint`).
