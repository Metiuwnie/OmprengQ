## 3. Ukuran Bundel & Kepatuhan Prinsip PRD

- **Pemisahan bundel (*code splitting*):** Seluruh rute admin dan publik di-*lazy load* di [App.tsx](../../apps/web/src/App.tsx). Hasil `vite build`:
  - `public-today`: `5.29 kB` gzip (`22.06 kB` raw)
  - `public-week`: `1.70 kB` gzip (`4.97 kB` raw)
  - Total muatan awal `/s/:slug/hari-ini` (entry + CSS + `public-today` + helper) berada di kisaran `~139 kB` gzip (di bawah target `< 150 KB` gzip).
- **Tanpa label status gizi:** Grep kata terlarang (`obesitas`, `kurus`, `gemuk`, `stunting`, `gizi buruk`, `IMT`) di seluruh `apps/web/src` bersih (0 temuan).
- **Tanpa login & tanpa cookie:** Rute publik hanya memanggil `GET /api/public/*` yang bersifat read-only.
- **Target sentuh >= 44px & aksesibilitas:** Seluruh tombol dan tautan menggunakan `min-h-11` (`44px`), dukungan tombol `Escape` untuk keluar dari Mode Kelas, serta state loading/error/404 ramah dengan tombol *Coba lagi*.
