# Audit UI Milestone M5 — Kalkulator Selisih Gizi, Rekomendasi TRT & Peringatan Alergi

## 1. Skill Agen yang Dipanggil

1. **UI UX Pro Max & Design System**
   - Merujuk [MASTER.md](../../design-system/MASTER.md), [kalkulator-anak.md](../../design-system/pages/kalkulator-anak.md), dan [kalkulator-remaja.md](../../design-system/pages/kalkulator-remaja.md) menggunakan varian tema `[data-theme="anak"]` dan `[data-theme="remaja"]` di [tokens.css](../../apps/web/src/styles/tokens.css) serta kelas 3D claymorphism di [index.css](../../apps/web/src/index.css).
   - Mode Anak menyembunyikan angka gram/mg teknis di balik tombol *Lihat rincian*, menyediakan tombol *Untuk orang tua* sebelum akses kelola profil, serta memakai bahasa positif (`"Sudah tercukupi"`, `"Hampir penuh"`, `"Yuk tambah di rumah"`) tanpa warna merah untuk selisih gizi.
   - Mode Remaja menampilkan seluruh 6 zat gizi, kartu sorotan zat besi (*mencegah anemia* untuk remaja putri ≥ 10 tahun), serta perkiraan kalori aktivitas fisik opsional berbasis MET.


   - Temuan awal (1 em-dash di [calculator-profiles.tsx](../../apps/web/src/routes/calculator-profiles.tsx) dan 1 middle-dot string di [teen-mode-view.tsx](../../apps/web/src/features/calculator/components/teen-mode-view.tsx)) sudah diperbaiki.

     ```text

     ```
   - *(Catatan: pemeriksaan Lighthouse/DevTools interaktif pada browser belum dijalankan secara otomatis di sesi ini.)*

## 2. Ukuran Bundel & Kepatuhan Prinsip PRD

- **Code Splitting (`vite build`):**
  - `calculator`: `7.93 kB` gzip (`28.56 kB` raw)
  - `calculator-profiles`: `2.83 kB` gzip (`8.10 kB` raw)
  - `profile-wizard`: `4.01 kB` gzip (`10.96 kB` raw)
- **Tanpa label status gizi terlarang:** Terverifikasi melalui unit test statis di [calculator-scenarios.test.ts](../../apps/web/src/features/calculator/lib/calculator-scenarios.test.ts) (`0` temuan di seluruh komponen, hook, lib, dan rute kalkulator).
- **Privasi lokal:** Tidak ada request `POST`/`PUT`/`PATCH` maupun pengiriman data profil anak ke server; seluruh perhitungan memakai `@mbg/shared` di browser.
- **Aksesibilitas:** Target sentuh `min-h-11` (`>= 44px`), progress bar memakai `role="progressbar"` dengan `aria-valuenow`/`aria-valuemax`/`aria-valuetext`, dan seluruh kontrol interaktif memiliki `:focus-visible`.
