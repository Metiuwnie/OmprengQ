# Audit UI Milestone M2 — Dasbor Admin (Menu, Bahan TKPI, Sekolah & QR)

## 1. Skill Agen yang Dipanggil

1. **UI UX Pro Max** (`C:\Users\Administrator\.gemini\config\skills\ui-ux-pro-max\scripts\search.py`)
   - `"combobox autocomplete keyboard" --domain ux --max-results 3`
     - Pencarian bahan TKPI memakai fetch *debounced* (200 ms) dengan navigasi keyboard lengkap (`ArrowUp`, `ArrowDown`, `Enter`, `Escape`) serta fokus terlihat.
   - `"tabs keyboard accessible" --stack shadcn --max-results 2`
     - Tab jenjang (`SD 1–3`, `SD 4–6`, `SMP`, `SMA`) memakai `role="tablist"`, `role="tab"`, `aria-selected`, dan navigasi panah kiri/kanan.
   - `"calendar schedule status" --domain ux --max-results 2`
     - Umpan balik status submit yang jelas (loading, sukses, error `role="alert"`) serta pembaruan jumlah item yang kontekstual.
   - `"data table responsive filter" --domain ux --max-results 3` & `"table checkbox" --stack shadcn --max-results 2`
     - Tabel semantik (`<table><thead><tbody>`) dengan pembungkus `overflow-x-auto` di desktop (`md:`) dan tata letak kartu bertumpuk di layar `360px` agar bebas gulir horizontal, serta pembungkus chip (`flex-wrap`) tanpa kliping.

## 3. Kepatuhan Prinsip PRD & Aksesibilitas

- **Tanpa label status gizi:** Grep kata terlarang (`obesitas`, `kurus`, `gemuk`, `stunting`, `gizi buruk`, `IMT`) di seluruh `apps/web/src` bersih (0 temuan).
- **Perhitungan tunggal `@mbg/shared`:** Panel gizi langsung pada [nutrition-panel.tsx](../../apps/web/src/features/admin/components/nutrition-panel.tsx) memakai `computePortionTotals` dan `collectPortionAllergens` yang sama dengan backend, disertai catatan *"Perkiraan berdasarkan TKPI"*.
- **Target sentuh >= 44px & angka tabular:** Kontrol tombol, input, select, dan tab jenjang minimal `44px` (`min-h-11`); angka gizi memakai `tabular-nums`.
- **Responsif 360px & 1280px + Print QR:** Kalender bulanan, daftar sekolah, dan daftar bahan beralih ke kartu ringkas di bawah `md`, serta `@media print` menyembunyikan navigasi (`.no-print`) saat mencetak kartu QR sekolah.
