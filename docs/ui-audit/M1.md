## 3. Kepatuhan Prinsip PRD & Aksesibilitas

- **Tanpa label status gizi:** Grep terhadap kata terlarang (`obesitas`, `kurus`, `gemuk`, `stunting`, `gizi buruk`, `IMT`) pada `apps/web/src` bersih (0 temuan).
- **Target sentuh >= 44px:** `Input`, `Button`, tautan navigasi sidebar/header, tombol toggle sandi, dan tombol menu seluler semuanya memakai `min-h-11` (`44px`) dan `min-w-11` untuk tombol ikon.
- **State interaktif lengkap:** Seluruh kontrol interaktif memiliki `:focus-visible`, `:active`, `:disabled`, serta penanganan state loading/error yang jelas.
- **Responsif 360px & 1280px:** Header seluler menjaga elemen ringkas (`Menu`, judul, tombol `Keluar`), sidebar beralih ke drawer di bawah `lg`, dan `overflow-x: clip` aktif pada `html, body`.
- **Ikonografi & Token:** Memakai SVG Lucide, tanpa emoji sebagai ikon, tanpa `transition: all`, tanpa hex literal di komponen UI, dan tanpa kartu bersarang (`Card` di dalam `Card`).
